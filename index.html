Installation Guide

1. I-download ang Cointab App sa iyong tablet.

2. I-download ang Owner Flasher sa iyong PC/Laptop.

3. Gamitin ang Flasher tool para i-set ang app bilang Device Owner (kailangan ito para sa Deep Freeze features).

4. Buksan ang app at i-set ang iyong custom rates sa Admin Panel.

5. Para sa wireless coinslot, i-connect ang NodeMCU sa parehong network.

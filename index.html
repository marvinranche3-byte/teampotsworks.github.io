Quick Start Guide

1. Download: I-install ang Cointab App sa iyong Android Tablet.

2. Flasher: Gamitin ang Owner Flasher sa PC para gawing "Device Owner" ang app. Ito ang susi para sa Deep Freeze security.

3. Permissions: I-allow ang lahat ng permissions (Accessibility, Overlay, Admin) para gumana ang Kiosk Mode.

4. Admin Setup: Pumasok sa Admin Settings gamit ang default code mo para i-set ang rates at piliin ang apps sa App Picker.

5. Ready: I-connect ang NodeMCU sa WiFi at simulan na ang iyong rental business!
